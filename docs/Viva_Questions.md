# Viva Questions — Campus Placement & Eligibility Portal

1. **What does the project do?** Manages student data, company drives, eligibility, applications and placement outcomes.
2. **Why did you make it a web app?** It can be accessed in a browser without a desktop-only GUI.
3. **What is HTML?** The markup language that structures web pages.
4. **What is CSS?** Styles the page layout, colors, responsiveness and typography.
5. **What is JavaScript used for?** UI interaction and calling backend REST APIs.
6. **What is Spring Boot?** A Java framework that simplifies creating stand-alone applications and web APIs.
7. **What is JDBC?** Java Database Connectivity, used to access relational databases from Java.
8. **What is JdbcTemplate?** Spring's helper for executing SQL and mapping query results with less boilerplate.
9. **Why MySQL?** It is a relational database suitable for structured records and relationships.
10. **What is a REST API?** An HTTP interface through which clients access and modify resources.
11. **What is GET used for?** Retrieving data.
12. **What is POST used for?** Creating a resource or submitting data.
13. **What is PATCH used for here?** Updating an application's status.
14. **What is DELETE used for?** Removing a record.
15. **What is JSON?** A text format used to exchange structured data between frontend and backend.
16. **What is a primary key?** A unique identifier for a database row.
17. **What is a foreign key?** A constraint linking a row to a record in another table.
18. **What is a unique constraint?** It prevents duplicate values in the constrained column(s).
19. **How is eligibility calculated?** CGPA must meet the threshold, backlogs must be within the limit and the drive must not be closed.
20. **How do you prevent duplicate applications?** A unique database constraint on student_id and company_id.
21. **What is JdbcTemplate?** A Spring abstraction over JDBC that manages common JDBC workflow.
22. **Why parameterized SQL?** It safely binds values and helps prevent SQL injection.
23. **What is a JOIN?** It combines related rows from multiple tables.
24. **What is CTC?** Cost to Company, commonly stated as an annual package.
25. **What is LPA?** Lakhs per annum.
26. **What are application statuses?** APPLIED, SHORTLISTED, REJECTED and PLACED.
27. **What is Maven?** A build and dependency management tool.
28. **What does responsive design mean?** Layout adapts to different screen sizes.
29. **What happens if MySQL is unavailable?** Backend database requests fail; the dashboard shows an error and the database service must be restored.
30. **What are future improvements?** Authentication, roles, resume uploads, notifications, interview scheduling and reports.
